# World Shock Lab

How the world, and Canada in particular, reacts to identified economic shocks: monetary policy surprises, oil supply news, and trade-policy and geopolitical risk.

**Status: M0 (planning). There are no results yet, and any number that appears in this repo is produced by code in it.**

- [docs/PLAN.md](docs/PLAN.md): scope, push-backs on the original brief, architecture, risks, milestone acceptance criteria
- [data/SOURCES.md](data/SOURCES.md): every data source, verified, with licence and redistribution policy
- [docs/EVALUATION_PROTOCOL.md](docs/EVALUATION_PROTOCOL.md) and [config/evaluation.yaml](config/evaluation.yaml): pre-registered out-of-sample protocol, frozen before any estimation
